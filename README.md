# intro

一个用于练习 **Trae 调用 GitHub** 的示例仓库。

## 项目简介

本仓库包含一个纯静态的个人介绍页面，作为练习 Trae 与 GitHub 协作流程的载体。通过这个仓库可以熟悉：创建与关联远程仓库、提交代码、推送到 GitHub，以及后续的分支与 PR 操作。

## 目录结构

```
intro/
├── index.html   # 纯静态个人介绍页面（内联样式，无依赖）
└── README.md    # 项目说明
```

## 查看页面

直接用浏览器打开 `index.html` 即可预览，无需安装任何依赖或启动服务。

## 仓库用途

- 练习 Trae 调用 GitHub 完成代码上传与同步
- 验证提交信息、分支管理与远程推送流程
- 作为静态页面托管的试验项目
